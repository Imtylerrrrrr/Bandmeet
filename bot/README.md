# Bandmeet 사설 봇 (v1) — 설정 가이드

> 빌드매뉴얼 §8 · §10. **봇은 추가 채널이지 코어가 아니다 — 봇이 죽어도 앱은 100% 작동**
> (앱에서 직접 조회 + 소집 메시지 복붙 가능). 봇은 **읽기 + 알림만** 한다.

## 동작 구조

```
[Bandmeet(Vercel)]  ──(outbox 적재)──>  /api/bot/poll  <──폴링── [24h PC: 안드 에뮬 + 메신저봇R]
                                          /api/bot/ack   <──발송표시──        │ replyRoom
                     <──(/합주봇 조회)──  /api/bot/schedule <──────────────────┘
```

- **아웃바운드(알림)**: 앱이 확정/충돌/소집을 `outbox` 에 적재 → 봇이 `poll` 폴링 → 단톡 게시 → `ack`(멱등 발송표시).
- **인바운드(조회)**: 단톡에서 `/합주봇` → 봇이 `schedule` 조회 → 일정 텍스트 답장. **상태 변경 없음.**
- **테넌트 라우팅**: 앱 `설정` 화면에서 운영진이 **단톡방 이름 ↔ 동아리**를 1회 연결(`chat_bindings`).

## 안전 규칙 (필수 — §8)

1. **읽기 + 알림만.** 봇은 투표/확정 등 상태를 절대 바꾸지 않는다(단톡 메시지 주입 차단).
2. **카카오 부계정**으로 운영 (본계정·동아리 보호). 정지 위험 인지.
3. **outbox 멱등.** `ack` 는 `sent_at IS NULL` 일 때만 표시 → 재호출 안전. 봇 크래시 시 미ack 메시지는 다음 폴링에 재게시(at-least-once; 드물게 중복 게시 가능).
4. **단톡방 ↔ org 바인딩** 1회 설정. 미바인딩 방엔 봇이 침묵/안내만.
5. **백엔드 못 닿으면 침묵.** 에러를 단톡에 토하지 않는다.

## 설정 순서

1. **Vercel 환경변수** `BOT_SECRET` 등록(임의 난수). 봇 기기에도 동일 값 사용.
2. 앱 **설정(`/settings`)** 에서 운영진이 단톡방 이름을 동아리에 연결.
3. **24h PC** 에 안드로이드 에뮬레이터 + 카카오톡(**부계정** 로그인) + 메신저봇R 설치.
4. 메신저봇R 새 봇 생성 → `bandmeet-bot.js` 내용 붙여넣기 → 상단 상수 3개 채우기:
   - `BASE_URL` = 배포 주소(`https://...vercel.app`)
   - `BOT_SECRET` = 1번 값
   - `ROOM_NAME` = 2번에서 연결한 단톡방 이름(정확히 일치)
5. 봇 **컴파일 ON** → 알림 접근 권한 허용 → 해당 단톡방에서 동작 확인.

## API (참고 — 모두 `Authorization: Bearer <BOT_SECRET>`)

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/api/bot/poll?room=<이름>` | 그 방 org 의 미발송 알림 `{messages:[{id,body}]}` |
| POST | `/api/bot/ack` `{ids:[...]}` | 발송 표시(멱등) `{ok,acked}` |
| GET | `/api/bot/schedule?room=<이름>&days=7` | 다가오는 일정 텍스트 `{text}` |

> ⚠ 메신저봇R 버전마다 HTTP/리스너 API 가 달라 `bandmeet-bot.js` 는 **템플릿**입니다.
> 기기 버전에 맞게 `httpGet/httpPost`(jsoup)·`bot.send`·`addListener` 부분을 조정하세요.

## 멀티테넌트 주의 (§8 일관성 플래그)

사설 봇은 **v1 단일 동아리 단톡 전용.** 유료 확장(여러 동아리) 단계엔 동아리마다 봇 계정·운영이 곱해져 안 맞음 → **아웃바운드를 알림톡(공식)으로 전환.** 코어 제품을 사설 봇 위에 짓지 말 것.
